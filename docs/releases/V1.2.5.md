# ChessAsh v1.2.5

I fixed a couple of layout issues that came up after v1.2:

- The top navigation now stays visible while scrolling on Windows and Android, so you can switch between Review and Library, open Settings or import a game without scrolling back up.
- On Windows, shorter windows keep a larger board and scroll vertically when needed instead of shrinking the board.

Search and filters still scroll with the library.
