# ChessAsh v1.4

I upgraded the animations, added move sounds and improved the tutor.

- Animations got an upgrade. Sound sacrifices have a spotlight sequence, and checks, stalemate and checkmate have their own effects.
- Skipping quickly through moves adds speed trails and a soft smear to the moving pieces.
- Arrow buttons, other controls and the selected move have smoother feedback.
- Move sounds use a soft wooden tap when you play moves, step through a game or practice in Training. You can turn them on in Settings.
- Fixed the Android interface spacing around the phone’s status bar and navigation area.
- Windows now opens maximized.
- The tutor has clearer instructions for explaining moves, using the engine’s findings and following the current position.
- Tutor replies support formatted text, including bold text, lists and code.
