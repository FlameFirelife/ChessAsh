# Credits

ChessAsh by FlameDev.

Foxash powers Windows move classification, review moments and retry guidance, along with training priorities, coaching focus and repeat intervals. Foxash was created by FlameDev Studios and is available at [github.com/FlameFirelife/foxash](https://github.com/FlameFirelife/foxash/).

Chess analysis uses Stockfish.js and the Stockfish contributors' engine. Chess legality and PGN handling use chess.js. The current chess-piece SVG artwork is original to ChessAsh. Interface icons are Lucide. Fonts are Host Grotesk and Atkinson Hyperlegible Mono.

Full third-party sources and licences are in THIRD_PARTY_NOTICES.md and the bundled licence files. ChessAsh is independent and is not affiliated with Chess.com or Lichess.

The super-king coach SVG is original ChessAsh vector artwork in public/coach/super-king.svg.
