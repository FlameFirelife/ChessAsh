# Bundled Foxash runtime

Foxash by FlameDev Studios: [github.com/FlameFirelife/foxash](https://github.com/FlameFirelife/foxash/).

This folder contains the Foxash 1.4.0 release executable, its MIT licence and corresponding source archive copied from the user's local Foxash repository. ChessAsh executes the bundled `rules/review.foxash` policy without requiring users to install Foxash separately. 

Windows also executes `rules/training.foxash` to select practice focus, rank training positions and schedule repeat attempts. The same runtime supports both scripts; no language-runtime upgrade is required for this integration. See `rules/README.md` for the protocols and parity checks.
