# Bundled Foxash runtime

Foxash by FlameDev Studios: [github.com/FlameFirelife/foxash](https://github.com/FlameFirelife/foxash/).

This folder contains the Foxash 1.4.0 release executable, its MIT licence and corresponding source archive copied from the user's local Foxash repository. ChessAsh executes the bundled `rules/review.foxash` policy without requiring users to install Foxash separately. The original language repository was not modified.
